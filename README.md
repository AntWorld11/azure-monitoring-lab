# Azure Monitoring Lab

Built an Azure monitoring and alerting lab using Azure Monitor, Log Analytics, and Virtual Machines.

## What I Configured

* Created an Azure Resource Group
* Deployed an Ubuntu Virtual Machine
* Configured a Virtual Network and Network Security Group
* Created a Log Analytics Workspace
* Enabled Diagnostic Settings
* Configured Azure Monitor alerts for VM activity

## Purpose

This lab was built to practice cloud monitoring, logging, and alerting in Microsoft Azure.

## Technologies Used

* Microsoft Azure
* Azure Monitor
* Log Analytics Workspace
* Virtual Machines
* Networking
* Diagnostic Settings
* Alert Rules

## Skills Demonstrated

* Cloud resource deployment
* Monitoring and alert configuration
* Log collection and analysis
* Azure networking fundamentals
* Troubleshooting and system visibility

## Real-World Use

Azure monitoring and alerting are commonly used by IT teams to:

* Monitor server health
* Detect configuration changes
* Troubleshoot issues
* Track security and administrative activity
* Automate operational awareness
